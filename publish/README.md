# 화두에너지솔루션 — 퍼블리싱 결과물 (HTML / CSS / JS)

PHP 환경에 그대로 올려 쓰실 수 있는 퍼블리싱 파일입니다. 별도 빌드 도구나 프레임워크가 필요 없습니다.

**화면(마크업·스타일)만 들어 있습니다.** 데이터 연동, 폼 전송, 검색·페이징, 관리자 기능은 들어 있지 않습니다.

**`php/` 와 `html/` 두 폴더로 나눠 담았습니다. 쓰실 쪽 폴더 안의 내용을 사이트 루트에 그대로 올리시면 됩니다.**

| 폴더 | 내용 | 언제 쓰나 |
| --- | --- | --- |
| `php/` | 머리말·꼬리말이 `include` 로 연결된 `.php` 페이지 | PHP 환경에 올려 쓰실 때 (권장) |
| `html/` | 머리말·꼬리말이 파일 안에 그대로 들어 있는 `.html` 페이지 | 화면·스타일을 바로 확인하실 때 |

두 폴더 모두 `assets`, `images`, `fonts`, `include`, `sub` 를 각각 갖고 있어서 그대로 독립 실행됩니다.
안쪽 링크도 각 폴더에 맞게(.php / .html) 들어가 있습니다.

**`html/` 안의 파일은 서버 없이 더블클릭으로 바로 열어보실 수 있습니다.** 경로를 상대 경로로 바꾸고
웹폰트를 CSS 안에 심어 두어, 파일을 그냥 열어도 글꼴·이미지·스타일이 그대로 나옵니다.
(그래서 `html/assets/css/site.css` 는 폰트를 품고 있어 용량이 큽니다. 실제 서비스에는 `php/` 쪽을 쓰세요.)

게시판과 충전사업자 순위에는 **샘플 데이터**가 들어 있어 데이터 등록 전에도 화면을 확인하실 수 있습니다
(프로모션 4건 · 설치사례 6건 · 공지 3건 · 순위 급속/완속 각 50위).
HTML 은 2칸 들여쓰기로 정리되어 있고, 영역마다 구분 주석을 넣어 두었습니다. (`<em>`, `<b>`, `<a>` 같은 인라인 요소는 줄을 나누면 없던 공백이 생기므로 한 줄로 두었습니다.)

## 폴더 구조

```
(php/ 와 html/ 각각 아래 구성이 들어 있습니다)

index                           메인
sub/  compare/ ranking          충전사업자 순위 (전체보기 팝업 포함)
               index            한 눈에 비교
      partners/index            제휴 충전사업자
      fire/    index            화재안전용품
               extinguisher / blanket / sprinkler / thermal / barrier
      support/ promotion        프로모션 목록
               promotion-view   프로모션 상세
               faq              자주 묻는 질문
               notice           공지·소식 목록
               notice-view      공지·소식 상세
               cases            설치사례
      about/   index            회사소개
               business / why / partners
      service/ index            설치·운영
               product / install / operation / process
      diagnosis/index           설치진단
      consult/ index            설치 상담 1단계 (주소 검색 전)
               step1-found      설치 상담 1단계 (주소 검색 후)
               step2            설치 상담 2단계 (정보입력)
               step3            설치 상담 3단계 (신청완료)
include/ header                 전 페이지 공통 머리말
         footer                 전 페이지 공통 꼬리말 (푸터·플로팅·팝업·스크립트 태그)
assets/css/site.css             전체 스타일 (한 파일)
assets/js/site.js               전체 스크립트 (한 파일, 라이브러리 없음)
images/  fonts/                 이미지와 웹폰트
favicon.ico  apple-icon.png
```

하위 페이지는 `sub/` 아래에 대메뉴별 폴더로 묶었습니다. 예를 들어 고객지원 4개 페이지는
모두 `sub/support/` 안에 있습니다.

경로는 모두 루트 기준(`/images/...`, `/sub/support/faq.html`)입니다.
하위 폴더에 설치하실 경우 `site.css`·HTML 안의 경로 앞에 그 폴더명을 붙여 주세요.

## 머리말·꼬리말 include

모든 페이지가 똑같이 쓰는 부분을 `include/` 폴더로 빼 두고, **`.php` 판에는 이미 연결해 두었습니다.**

```php
<body>
  <?php include __DIR__ . '/../../include/header.php'; ?>
  <main> … 이 페이지만의 내용 … </main>
  <?php include __DIR__ . '/../../include/footer.php'; ?>
</body>
```

| 파일 | 내용 |
| --- | --- |
| `include/header.php` | `<header class="hd">` 전체 (로고 · 상단 메뉴 · 전체메뉴 · 햄버거) |
| `include/footer.php` | `<footer class="ft">`, 플로팅 버튼, 상담 말풍선, 상담·약관 팝업, 스크립트 태그 |

`__DIR__` 기준이라 폴더 깊이는 이미 맞춰져 있습니다 (메인은 `/include/…`, `sub/대메뉴/` 안은 `/../../include/…`).

`html/` 쪽은 머리말·꼬리말이 파일 안에 그대로 들어 있어 서버 없이 바로 열어 확인하실 수 있습니다.
`php/` 쪽만 쓰실 거라면 `html/` 폴더는 지우셔도 됩니다.

## 파일 안의 영역 구분 주석

파일마다 맨 위(`<!DOCTYPE html>` 바로 아래)에 그 페이지가 어떤 영역으로 이루어져 있는지
목차 주석을 넣어 두었습니다. 파일을 열면 전체 구성이 먼저 보입니다.

```html
<!--
  화두에너지솔루션 — 메인

  이 파일의 영역 구성
  공통 · 상단 헤더
  ── 본문 ──
  01. 메인 비주얼
  02. 실적 숫자
  ...
  공통 · 하단 푸터
-->
```

본문 영역은 목차와 같은 번호·이름으로 시작과 끝을 감싸 두었습니다.

```html
<!-- ============== 03. 서비스 안내 ============== -->
<section class="sec services"> … </section>
<!-- ============== 03. 서비스 안내 끝 ============== -->
```

영역 안의 작은 덩어리에는 이름만 한 줄로 붙여 두었습니다.
예: `<!-- 검색 · 분류 필터 -->`, `<!-- 전체메뉴 패널 -->`, `<!-- 전체보기 팝업 -->`

`공통 ·` 으로 시작하는 영역은 모든 페이지가 완전히 동일하므로, 그 주석 사이를
그대로 잘라 `header.php` / `footer.php` 로 쓰시면 됩니다.

## 페이지를 PHP로 옮길 때

- 머리말·꼬리말은 위의 `include/` 폴더 설명을 참고해 주세요.
- 반복 출력이 필요한 영역은 HTML 주석으로 표시해 두었습니다.
  예: `<!-- 반복 시작: 목록 한 줄 -->` … `<!-- 반복 끝: 목록 한 줄 -->`
- 목록·상세 페이지(공지, 프로모션, 설치사례)와 충전사업자 순위에는 **샘플 데이터**가 들어 있습니다.
  게시판 글은 제목이 `[샘플]`, 순위는 사업자명 뒤에 `샘플N` 으로 표시했습니다.
  순위는 50위까지 채워 두었으니 전체보기 팝업에서 표 안쪽 스크롤을 확인해 보실 수 있습니다.
  실제 데이터로 교체해 주세요.
- 이용약관·개인정보처리방침은 별도 페이지가 아니라 **푸터에서 여는 팝업**(`<dialog class="lmodal">`)입니다.
  두 문서가 한 팝업 안에 모두 들어 있고, 버튼의 `data-legal` 값(`terms` / `privacy`)에 따라
  보이는 쪽만 바뀝니다. 내용은 `include/footer.php`(= `footer.html`) 안에 있습니다.

## 메인 배너

메인 첫 화면의 왼쪽은 글자가 아니라 **이미지 한 장**(`/images/main-banner.jpg`)입니다.

```html
<div class="hero__banner">
  <img class="hero__img hero__img--pc" src="/images/main-banner.jpg" alt="...">
  <!-- 모바일 이미지를 따로 쓰실 때만 추가 -->
  <img class="hero__img hero__img--mo" src="/images/main-banner-mo.jpg" alt="">
</div>
```

- PC 이미지만 넣으면 모바일에서도 그 이미지를 줄여서 보여줍니다.
- 모바일용 이미지를 따로 쓰시려면 위처럼 `hero__img--mo` 를 하나 더 넣고
  바깥 `div` 에 `data-split` 속성을 붙여 주세요. 768px 이하에서 자동으로 바뀝니다.
- 바로 아래 주황색 버튼은 글자와 링크를 그대로 고치시면 됩니다.

```html
<div class="hero__cta">
  <a class="btn btn--orange hero__btn" href="/index.html#diagnosis">충전기 설치 진단 …</a>
</div>
```

## 설치 상담 (sub/consult/)

주소 검색 → 정보입력 → 신청완료 3단계입니다. 정적 파일이라 단계마다 파일을 따로 두었고,
`assets/js/site.js` 가 버튼에 맞춰 다음 파일로 보냅니다 (화면 확인용 이동일 뿐, 실제 검색·접수는 아닙니다).

```
index.html        1단계 — 주소 검색 전 (다음 버튼 비활성)
step1-found.html  1단계 — 주소 검색 후 (결과 카드 + 다음 버튼 활성)
step2.html        2단계 — 충전기 수량 · 기본정보 입력
step3.html        3단계 — 신청 완료
```

PHP 로 옮기실 때는 한 파일에서 단계만 바꿔 보여주셔도 됩니다.

- **주소 검색 결과는 예시 값**입니다. 단지 정보 API 가 붙으면 `.addr` 영역의 값만 바꾸면 됩니다.
  (기본 정보 4줄 + 현재 충전기 설치 현황 표)
- 메인의 주소 검색창에서 검색하면 `설치 주소 확인` 팝업(`<dialog class="amodal">`)이 열리고,
  다음을 누르면 2단계로 넘어갑니다.
- 2단계 폼에 들어 있는 입력칸 이름: `fast_now`(급속 기설), `slow_now`(완속 기설),
  `slow_add`(완속 추가), `fast_total`·`slow_total`(합계), `cpo`, `building`,
  `name`(신청자), `phone`(연락처), `agree`, `address`,
  `website`(봇 차단용 숨은 값 — 값이 있으면 저장하지 마세요).
  **전송과 합계 계산은 붙어 있지 않습니다.**

## 서버 연동이 필요한 지점 (HTML 안에 주석으로 표시해 두었습니다)

아래는 모두 **화면만 있고 동작은 붙어 있지 않습니다.**

| 위치 | 붙이실 때 |
| --- | --- |
| 메인 상담 폼 `form.consult` | `action` 과 `method` 를 넣어 주세요 |
| 상담 접수 팝업 `.cmodal__form` | `action="/consult.php" method="post"` 처럼 |
| 설치 상담 2단계 `form.cw__panel` | 같은 방식으로 |
| 게시판 검색·분류 필터 `.board__bar`, 더보기 `.board__more` | PHP 조건 검색·페이징으로 |
| 주소 검색 `form.finder__bar` | 단지 조회 결과로 `.addr` 영역을 채워 주세요 |

상담 폼 입력칸 이름: `cpo`(충전사업자), `building`(건물용도), `name`(이름), `phone`(연락처), `address`(주소), `agree`(개인정보 동의), `website`(봇 차단용 숨은 값 — 값이 있으면 저장하지 마세요).

## 스크립트 (assets/js/site.js)

화면을 눈으로 확인하는 데 필요한 동작만 들어 있습니다. 라이브러리는 쓰지 않습니다.

**들어 있는 것**

1. 스크롤 등장 효과 — `data-reveal`, `data-reveal-group` 속성이 붙은 요소
2. 헤더 전체메뉴(마우스오버·Esc·바깥 클릭)와 모바일 햄버거
3. FAQ 아코디언 — 플러스가 45° 회전, 답변 높이 전환
4. 브랜드 무한 슬라이드 — 마크업의 카드는 [복제·원본·복제] 3세트이며 스크립트가 위치를 잡습니다.
   카드를 추가·삭제하실 때는 세 세트의 개수를 똑같이 맞춰 주세요.
5. 실적 숫자 카운트업
6. 팝업 열고 닫기 — 상담 신청(`.cmodal`), 설치 주소 확인(`.amodal`), 약관(`.lmodal`)
7. TOP 버튼
8. 충전사업자 순위 — 운영대수 / 충전요금 전환, 1위부터 차례로 굴러가는 강조
9. 순위 전체보기 팝업 — PC 는 표 안쪽 스크롤, 모바일(768px 이하)은 표를 열었다 접었다
10. 설치 상담 단계 사이 화면 이동 (`sub/consult/` 안의 파일끼리)

**들어 있지 않은 것 — 서버단에서 붙여 주세요**

| 화면 | 지금 상태 | 붙이실 곳 |
| --- | --- | --- |
| 게시판 검색 · 분류 필터 · 더보기 | 모양만 있고 동작하지 않습니다 | `.board__bar`, `.board__more` |
| 메인 상담 폼 | 전송되지 않습니다 | `form.consult` |
| 상담 접수 팝업 | 전송되지 않습니다 | `.cmodal__form` 에 `action`·`method` |
| 주소 검색 | 팝업만 열립니다. 결과는 고정된 예시 값입니다 | `form.finder__bar`, `.addr` 영역 |
| 설치 상담 2단계 폼 | 전송되지 않습니다. 합계도 자동 계산되지 않습니다 | `form.cw__panel` |

접근성 설정에서 '동작 줄이기'를 켠 사용자에게는 애니메이션이 자동으로 꺼집니다.

## 스타일 (assets/css/site.css)

파일 맨 위 `:root` 에 색상·글자 크기·콘텐츠 폭이 변수로 정리되어 있습니다.

```css
--container: 1300px;   /* 콘텐츠 최대 폭 */
--navy / --purple / --orange / --mint   /* 포인트 색 */
--fs-h2 / --fs-h3 / --fs-body           /* 제목·본문 크기 */
```

반응형 분기: 1600 / 1440 / 1280 / 1100(태블릿 가로) / 900(태블릿 세로) / 768(모바일)

## 웹폰트

- 제목: 여기어때 잘난체 고딕 (`fonts/JalnanGothic.woff2`) — 사이트에서 쓰는 글자만 남긴 서브셋
- 본문·숫자: Noto Sans KR (`fonts/NotoSansKR-Variable.subset.woff2`) — 굵기 400~900 가변 폰트

두 글꼴 모두 `fonts/` 폴더에서 직접 불러옵니다. 외부(Google Fonts 등)에 연결하는 곳은 없습니다.

## 공유 미리보기 · 파비콘

- 파비콘 `favicon.ico` (16/32/48/64), 모바일 홈 화면 아이콘 `apple-icon.png` (180×180)
- 카카오톡·메신저 미리보기: `<head>` 의 `og:image` 가 `/images/og-image.png` (800×400) 를 가리킵니다.
  `og:url`, `og:image` 의 도메인은 지금 테스트 주소로 들어가 있으니, 실제 도메인으로 바꿔 주세요.
- 페이지마다 `<title>` 과 `<meta name="description">` 이 들어 있습니다. 문구는 자유롭게 고치셔도 됩니다.

## 브라우저

크롬·엣지·사파리 최신 버전 기준으로 확인했습니다. 팝업은 `<dialog>` 요소를 사용합니다.
